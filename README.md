# Student Portal

## Описание проекта

Student Portal — это простое веб-приложение для студентов.

С помощью приложения студент сможет просматривать информацию о себе,
учебные предметы, расписание и оценки.

## Основные разделы

- Профиль студента
- Предметы
- Расписание
- Оценки

## Используемые технологии

- HTML
- CSS
- Git

## Цель проекта

Создать простое веб-приложение для работы с учебной информацией
студента и изучить процесс командной разработки с использованием
Git, GitHub, GitLab и Jenkins.

## Командная работа (Git Workflow)

### Роли участников

1. Гренадер Владислав — разработчик, отвечает за Git, ветки и объединение изменений.
2. Хафизов Шамиль — разработчик интерфейса, отвечает за профиль студента, предметы и расписание.
3. Муслимова Ажар — тестировщик, проверяет работу сайта, находит ошибки и помогает их исправлять.

### Правила работы с Git

- main — основная стабильная версия проекта.
- dev — ветка для объединения готовых изменений.
- feature/* — отдельные ветки для разработки новых функций.
- Каждый участник работает над своей задачей в отдельной ветке.
- Перед началом работы нужно получить последние изменения из общего репозитория.
- Изменения необходимо сохранять с помощью commit.
- Перед объединением изменений нужно проверить код.
- Если возникает конфликт слияния, участники исправляют его вручную.
- Готовые изменения объединяются в dev.
- В main переносится проверенная версия проекта.

### Порядок работы

1. Создать отдельную ветку для своей задачи.
2. Изменить необходимые файлы.
3. Сохранить изменения с помощью commit.
4. Отправить ветку в общий репозиторий.
5. Создать Pull Request для проверки изменений.
6. После проверки объединить изменения в dev.
